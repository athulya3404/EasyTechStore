Expected Column Headers:

Column Description
Product Name * e.g. HP Pavilion 15, Dell XPS 15 (Required)
Category * e.g. Laptops, Smartphones (Required)
Brand e.g. HP, Dell, Apple, Sony, Samsung (Optional)
Price * Base selling price, e.g. 850.00 (Required)
Discount (%) Discount percentage (0-100), e.g. 10 (Default: 0)
Stock Inventory quantity units in stock (Default: 0)
Photo URL Web photo URL (e.g. https://.../laptop.jpg) or local media path (Optional)
Specifications Hardware specs: RAM, Processor, Display, Storage
Description Full product description (Optional)
Active Yes or No (Default: Yes)
  • Products already existing in the store will NOT be overwritten; existing product data is safely preserved.
  • If a Category or Brand does not exist yet, it will be automatically created.
  • Brands will automatically be linked under the specified category (e.g. HP under Laptops).
  • Empty rows will be automatically skipped.
